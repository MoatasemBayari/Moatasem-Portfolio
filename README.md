# Moatasem Bayari - Portfolio

A brighter charcoal, project-led portfolio with lime accents. Responsive, keyboard accessible, no runtime dependencies, expandable project notes, and native screenshot viewer.

## Run

Node 22+: `npm run check` then `npm run build`. Serve `_site` with any static server. `resume.html` includes Print / Save as PDF.

## Publish

The GitHub Actions workflow builds and publishes to GitHub Pages on pushes to main. If Pages setup needs permission, open Settings  Pages and select GitHub Actions, then rerun the workflow.

## Content and assets

Project text, profile photo, and application screenshots originate from https://github.com/MoatasemBayari/MoatasemPortfolio . The build copies seven public images into the published site, so page views do not hotlink images. Future builds need the source images available. This does not modify the old repository.

The printable CV is a web adaptation of Moatasem_Bayari_Updated.pdf supplied previously by the owner. LinkedIn uses the verified existing profile. Employer projects are presented as case studies without fake demo or source-code links. Duplicate incorrect Salvage content from the old site was omitted.
